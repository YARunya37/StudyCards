# StudyCards
<img align="left" width="250" src="https://github.com/user-attachments/assets/e55bf94d-2f73-49ba-97c3-df7b135ec521" alt="StudyCards">

Приложение для создания, хранения и изучения учебных материалов.

Проект разрабатывается как учебная платформа для подготовки к экзаменам и самостоятельного обучения. Основная идея — предоставить единое пространство для хранения конспектов, генерации экзаменационных билетов и проверки знаний.

## Основные возможности

На текущий момент проект включает:

* создание и редактирование конспектов;
* хранение конспектов в локальном формате;
* генерацию экзаменационных билетов;
* прохождение тестирования по созданным билетам.

Планируемые возможности:

* интеграция с нейросетями;
* автоматическая генерация вопросов по конспектам;
* расширенная система тестирования;
* синхронизация данных между настольной и мобильной версиями приложения.

# Цель проекта

Проект развивается как долгосрочный учебный и портфолио-проект.

Основные цели:

* получение опыта промышленной разработки;

# StudyCards
<img align="left" width="250" src="https://github.com/user-attachments/assets/e55bf94d-2f73-49ba-97c3-df7b135ec521" alt="StudyCards">


**StudyCards** — это три инструмента в одном: редактор конспектов, генератор карточек и система тестирования. Приложение создано, чтобы избавить студентов от хаоса в подготовке. Больше не нужно прыгать между разными сервисами: пиши лекции в удобном формате, тут же превращай их в карточки для запоминания и проверяй себя на экзаменационных тренажерах. Вся подготовка — в одном окне.
